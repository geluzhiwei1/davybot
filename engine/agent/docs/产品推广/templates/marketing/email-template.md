## A/B Testing Guidelines

### Elements to Test
1. **Subject Lines**: Different wording, length, personalization
2. **Preheader Text**: Vary the preview text
3. **CTA Placement**: Test button position
4. **CTA Color/Text**: Different button colors and text
5. **Content Format**: Test different content structures
6. **Send Time**: Test different days/times

### Testing Process
1. Define hypothesis (what you're testing)
2. Create variations
3. Split test list (50/50 or 60/40)
4. Send simultaneously
5. Measure results after [X] hours
6. Declare winner based on open rate, CTR, or conversion
7. Apply learnings to future emails

---

## Best Practices

### Subject Lines
- Keep under 50 characters for best mobile display
- Use personalization when possible
- Create curiosity or urgency
- Avoid spam words and all caps
- Test different approaches

### Content
- Keep paragraphs short (2-3 sentences)
- Use bullet points for readability
- Focus on benefits, not features
- Include one clear CTA
- Optimize for mobile (60% of emails opened on mobile)

### Design
- Use responsive design
- Consider text-only version for email clients that block images
- Use alt text for all images
- Keep file sizes small for fast loading
- Test across different email clients

### Timing
- Test send times (Tuesday-Thursday often perform best)
- Consider time zones for global audiences
- Avoid sending on weekends or holidays
- Segment lists for optimal timing
